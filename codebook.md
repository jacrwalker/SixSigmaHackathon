# 🏥 Hospital Simulation Codebook
| **File Name**                          | **Purpose / Description**                                                                                                | **Key Components or Outputs**                                                                                                                                                                                                                                                                                                               | **Notes / Relationships**                                                                                                               |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **`config.py`**                        | Defines **global configuration constants** for the simulation, including staff counts, severity scales, and timing.      | - `PATIENT_SEVERITY_MIN`, `PATIENT_SEVERITY_MAX` (range 1–100)<br>- `N_PROVIDERS`, `N_NURSES`<br>- `INPATIENT_DAYS_GE50`, `INPATIENT_DAYS_LT50`<br>- `MINUTES_PER_DAY`<br>- `NURSES_MAX_PATIENTS`                                                                                                                                           | Acts as the central settings file. All other modules import from it. Adjust here to run alternate hospital scenarios.                   |
| **`patient.py`**                       | Defines the **`Patient` class**, representing a single hospital patient and their attributes over time.                  | Attributes include:<br>• `id`, `initial_severity`, `severity`<br>• `admit_time`, `discharge_time`, `discharge_reason`<br>• `waiting_time`, `total_time_in_hospital`, `average_waiting_period`<br>• `waiting_periods` (list of per-wait durations)<br><br>Methods:<br>• `start_waiting()` / `stop_waiting()`<br>• `to_dict()` for CSV export | Central data structure used in the simulation. Each patient evolves over time and interacts with staff.                                 |
| **`staff.py`**                         | Defines hospital staff roles and availability — **Providers (doctors)** and **Nurses**.                                  | Classes:<br>• `Provider` (doctor)<br>• `Nurse` (can handle multiple patients)<br>Function:<br>• `initialize_staff()` — creates lists of all providers and nurses.                                                                                                                                                                           | Staff are assigned to patients within the simulation loop in `simulation.py`. Nurse-to-patient ratios depend on configuration settings. |
| **`simulation.py`**                    | Core **simulation engine** — drives the hospital environment, manages time steps, patient updates, and staff allocation. | - Initializes patients and staff.<br>- Steps through time in minutes.<br>- Determines who is seen by staff.<br>- Updates waiting/treatment times.<br>- Triggers discharges.<br>- Compiles full report via `get_waiting_time_report()`.                                                                                                      | Imports from `patient.py`, `staff.py`, and `config.py`.<br>Outputs structured data to a CSV.                                            |
| **`main.py`**                          | **Main entry point** for the hospital simulation. Runs `Simulation()`, saves results, and prints summary stats.          | - Runs `sim.run()`.<br>- Exports results to `OUTPUT_CSV`.<br>- Displays top 20 patients’ summary with columns:<br> `patient_id`, `initial_severity`, `waiting_time_minutes`, etc.                                                                                                                                                           | Run this file with `python main.py` to start a full simulation. All results are generated automatically.                                |
| **`plot_wait_vs_initial_severity.py`** | Generates a **scatter plot** of **waiting time vs. initial severity**, using the simulation’s output CSV.                | - Reads `scratch_waiting_times_system.csv`.<br>- Computes correlation (r-value).<br>- Colors points:<br>🟩 Green → improved (severity ↓)<br>🟥 Red → worsened (severity ↑).<br>- Adds trendline (orange).<br>- Saves `wait_vs_initial_severity.png`.                                                                                        | Use this after running the simulation to visualize and analyze patient-level outcomes.                                                  |
| **`scratch_waiting_times_system.csv`** | Output dataset of patient-level simulation data. Each row = one patient.                                                 | **Columns:**<br>• `patient_id`<br>• `initial_severity` / `final_severity`<br>• `waiting_time_minutes` / `waiting_time_days`<br>• `average_waiting_period_minutes` / `average_waiting_period_days`<br>• `discharge_reason`                                                                                                                   | Generated automatically by `main.py`. Used as input for visualization and analysis scripts.                                             |
| **`wait_vs_initial_severity.png`**     | Visualization showing correlation between **initial severity** and **total waiting time**.                               | Scatter plot with:<br>• X-axis: Initial Severity<br>• Y-axis: Waiting Time (minutes)<br>• Color: Improvement vs. worsening<br>• Trendline + correlation                                                                                                                                                                                     | Produced by `plot_wait_vs_initial_severity.py`. Used for reports and presentations.                                                     |
