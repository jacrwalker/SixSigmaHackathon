# 🏥 Hospital Simulation Codebook
| **File Name**                        | **Purpose / Description**                                                                                                                           | **Key Variables / Columns**                                                                                                                                                                                                                                                                                                                                               | **Background Information (Data Collection Context)**                                                                                                                                                       |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **config.py**                        | Defines global configuration parameters used across the simulation (system settings, file paths, and constants).                                    | `N_PATIENTS` – total number of patients simulated.<br>`N_PROVIDERS` – number of medical providers available.<br>`N_NURSES` – number of nurses available.<br>`NURSES_MAX_PATIENTS` – maximum patients per nurse.<br>`OUTPUT_CSV` – filename for the generated dataset (`scratch_waiting_times_system.csv`).                                                                | Configuration values control simulation size, resource limits, and output file naming. Adjusting these parameters changes the simulated hospital load and staffing ratios.                                 |
| **main.py**                          | The main entry point that runs the full hospital simulation. It initializes the simulation, executes it, saves results, and displays a summary.     | *(No dataset variables — execution script)*                                                                                                                                                                                                                                                                                                                               | Running this file triggers `Simulation.run()`, which populates all patient events and writes the resulting data to a CSV for later visualization.                                                          |
| **simulation.py**                    | The core simulation logic that models patient arrivals, triage severity, waiting, and staff assignments. It produces the dataset used for analysis. | Generates variables such as:<br>`patient_id`<br>`initial_severity`<br>`final_severity`<br>`waiting_time_minutes`<br>`average_waiting_period_minutes`<br>`n_waiting_periods`                                                                                                                                                                                               | Represents a discrete-event simulation of a hospital system. Patients enter with randomized severity, are triaged by nurses or providers, and accumulate waiting times based on availability and priority. |
| **patient.py**                       | Defines the `Patient` class and how each patient’s attributes and experiences (severity, waiting time, status changes) are tracked.                 | `patient_id` – unique patient identifier.<br>`initial_severity` – severity at triage (1 = mild, 100 = critical).<br>`final_severity` – severity at end of simulation.<br>`waiting_time_minutes` – total accumulated wait time.<br>`average_waiting_period_minutes` – average wait per episode.<br>`n_waiting_periods` – number of discrete waiting intervals experienced. | Each patient record is dynamically updated through simulation events. Severity may improve or worsen based on time and care access. Data reflects synthetic but realistic care flow dynamics.              |
| **staff.py**                         | Defines the `Provider` and `Nurse` classes used in the simulation. Handles assignment logic and capacity tracking for staff.                        | `Provider.id`, `Provider.available`, `Provider.current_patient`<br>`Nurse.id`, `Nurse.available`, `Nurse.current_patient`, `Nurse.assigned_patients`                                                                                                                                                                                                                      | Staff entities simulate human resource constraints. Each provider or nurse can only manage a certain number of patients at once, introducing variability in patient waiting times.                         |
| **scratch_waiting_times_system.csv** | Output dataset containing all simulated patient records and their time metrics. Generated after running `main.py`.                                  | `patient_id`<br>`initial_severity`<br>`final_severity`<br>`waiting_time_minutes`<br>`average_waiting_period_minutes`<br>`n_waiting_periods`                                                                                                                                                                                                                               | Synthetic data produced by the simulation, representing how long patients of various severities waited before being seen. Used for performance analysis and plotting.                                      |
| **plot_wait_vs_initial_severity.py** | Reads the CSV file and produces a visual analysis (scatter plot) showing the relationship between patient severity and total waiting time.          | Reads:<br>`initial_severity`<br>`waiting_time_minutes`<br>`final_severity`<br>Computes derived variable: `severity_change` = `final_severity - initial_severity`                                                                                                                                                                                                          | Visualizes trends in the dataset. Green points = patients who improved (severity decreased), red points = patients who worsened. Outputs `initial_severity_vs_avg_wait.png`.                               |
| **initial_severity_vs_avg_wait.png** | Visualization output generated by `plot_wait_vs_initial_severity.py`.                                                                               | *(Image file — no variables)*                                                                                                                                                                                                                                                                                                                                             | Displays a scatter plot of initial severity vs waiting time, with color-coded outcomes and a trendline showing correlation. Used to analyze patient prioritization performance.                            |
